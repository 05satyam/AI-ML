# GenAI Interview Questions (Basic → Advanced)

Topic-wise question banks for **AI / GenAI / LLM engineer** interviews. Use them as a checklist: cover the answer, speak for ~60s, then check the cue.

## Start here

| Topic | File | Level coverage |
|-------|------|----------------|
| Basics of AI / ML | [basics-of-ai.md](basics-of-ai.md) | Foundational (+ links to existing repo drills) |
| LLMs & Transformers | [llm.md](llm.md) | Basic → Advanced (attention, KV cache, serving) |
| RAG | [rag.md](rag.md) | Basic → Advanced (hybrid search, evals, prod) |
| AI Agents | [ai-agents.md](ai-agents.md) | Basic → Advanced (ReAct, multi-agent, eval) |
| AI Agent Tools | [ai-agent-tools.md](ai-agent-tools.md) | Basic → Advanced (function calling, MCP, safety) |

## How to use

1. Pick one topic file per day.
2. Answer **without looking** at the cue notes.
3. For each Advanced question, force a **tradeoff** (latency / cost / quality / safety).
4. Pair with hands-on notebooks in [`../`](../) (RAG service, DSPy, senior-ai-engineer).
